# 0.1 から 0.2.0 への移行表

SKAM の 6 つの公開パッケージ (`@kanbun-skam/skam`、`skam-xml-parser`、`skam-xml-stringify`、`skam-html-renderer`、`skam-canvas-renderer`、`skam-web-component`) は、0.2.0 で版をそろえて公開します。0.1.x からの変更のうち、利用者の挙動に関わるものをすべて、旧挙動・新挙動・回避策の対応で示します。

各パッケージの README の「0.1 からの移行」には、そのパッケージを対象に含む行を再掲しています。CHANGELOG には、全行の ID と 1 行の要約を載せています。
