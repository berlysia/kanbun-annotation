# SKAM 簡易記法

白文に訓点を打つための、手で打つ平文の記法。`@kanbun-skam/skam-text-parser` が SKAM 文書（JSON）に変える。記法から SKAM への片方向で、SKAM から記法へは書き出さない。決定の経緯は [ADR-048](decisions/adr-048-text-notation.md) にある。

playground では、エディタの上の「簡易記法」を選ぶと記法で打てる。打った文はその場で描画され、誤りは行と桁つきで一覧に出る。記法の入力中は、返り点や仮名を付ける GUI の編集ボタンとファイルの開く・保存は使えない。

## 書き味

既定の記号で書いた例と、できる注記を示す。

### 読み仮名・送り仮名・返り点・句読点

```
學（まな）びて而時に習ふ＜レ＞之を。不＜二＞亦た說（よろこ）ばしから＜一＞乎。
```

- 學: 読み仮名 `まな`、送り仮名 `びて`
- 時: 送り仮名 `に`
- 習: 送り仮名 `ふ`、習の後ろに返り点 ㆑
- 之: 送り仮名 `を`、之の後ろに句点
- 不: 不の後ろに返り点 ㆓
- 亦: 送り仮名 `た`
- 說: 読み仮名 `よろこ`、送り仮名 `ばしから`、說の後ろに返り点 ㆒
- 乎の後ろに句点
- 本文の字は 學 而 時 習 之 不 亦 說 乎 の 9 字

### 再読文字

```
過ぎたるは猶（な）ほ｛ごとし｝＜レ＞不ざるが＜レ＞及ば。
```

- 猶: 再読文字。1 回目は読み `な`・送り仮名 `ほ`、2 回目は送り仮名 `ごとし`。猶の後ろに返り点 ㆑
- `｛…｝` を書いた字の読み仮名と送り仮名は、再読文字の 1 回目になる
- 2 回目に読み仮名が要るときは `｛（よみ）おくり｝` と書く

### 竪点と範囲の読み仮名

```
｜所＜二＞ー以（ゆゑん）
```

- 所 と 以 を竪点でつなぐ。所の後ろ（竪点の語の中の字間）に返り点 ㆓
- 所〜以 の範囲に読み仮名 `ゆゑん`。`｜` は範囲の読み仮名の始まり

### 添え仮名

```
習ふ＜レ＞之＋を。
```

- 之: 添え仮名 `を`。`之を` と書けば送り仮名になる

### 改行とブロック

```
學（まな）びて而時に習ふ＜レ＞之を。
不＜二＞亦た說（よろこ）ばしから＜一＞乎。

有り＜レ＞朋自り＜二＞遠方＜一＞來たる。
```

- 空行で区切った 2 つのブロックになる
- 1 つ目のブロックの中の改行は、之の後ろの改行（linebreak）になる

## 既定の記号とキー

日本語 IME のローマ字入力で、JIS 配列と US 配列のどちらでも打てる記号を選んでいる。全角と半角のどちらも同じ意味で受ける。

| 機能                   | 既定の記号                             | JIS 配列      | US 配列       |
| ---------------------- | -------------------------------------- | ------------- | ------------- |
| 返り点                 | `＜＞` `<>`                            | Shift+`,` `.` | Shift+`,` `.` |
| 竪点                   | `ー` `-` `－`                          | `-`           | `-`           |
| 句読点                 | `。`（句点）`、`（読点）`・`（その他） | `.` `,` `/`   | `.` `,` `/`   |
| 読み仮名               | `（）` `()`                            | Shift+`8` `9` | Shift+`9` `0` |
| 再読の 2 回目          | `｛｝` `{}`                            | Shift+`[` `]` | Shift+`[` `]` |
| 範囲の読み仮名の始まり | `｜` `\|`                              | Shift+`¥`     | Shift+`\`     |
| 添え仮名               | `＋` `+`                               | Shift+`;`     | Shift+`=`     |
| escape                 | `＼` `￥` `\` `¥`                      | `¥`           | `\`           |

- `「」『』` は、後の版の引用のために予約している。書くと誤り（`RESERVED_SYMBOL`）になる。本文の字にするには `＼「` と書く
- 両方の配列で Shift なしに打てる括弧は `[` `]`（IME で `「」`）だけだが、本文のカギ括弧と同じ記号になるので返り点には使わない
- JIS 配列の ATOK では、表のキーで `＜＞` `（）` `｛｝` `｜` `＋` `・` が出て、`-` は長音の `ー` ではなく全角のハイフン `－` になる。どれも既定の記号に入っている（2026-11-28 に実機で確認）。US 配列と、ATOK 以外の IME は実機で確かめていない

## 規則

### 字と書き込み

- 本文の字は、記号・仮名・空白でない書記素クラスタ 1 つ
- 字の後ろに書いた読み仮名・送り仮名・返り点・添え仮名・再読の 2 回目は、その字に付く。次の本文の字・句読点・改行・`｜` までが 1 つの字の書き込みで、順は問わない（`習ふ＜レ＞` と `習＜レ＞ふ` は同じ）
- 1 つの字に同じ種類の書き込みは 1 つだけ。返り点だけは複数書けて、書いた順に並ぶ（`＜一＞＜レ＞` と `＜一レ＞` は同じ）
- 送り仮名は、字の後ろの平仮名・片仮名の連なり。打ったとおりに持ち、平仮名と片仮名を変換しない。長音の `ー` と中黒の `・` は仮名に含めない
- 返り点の中に書けるのは `レ`（`れ` も可）、`一二三四`、`上中下`、`甲乙丙丁`、`天地人`、U+3191〜U+319F の訓点文字。返り点は書いた字の後ろに置く（竪点の語の中の返り点も同じ）
- 読み仮名・再読・添え仮名の値は仮名だけ
- 句読点は直前の字の後ろに置く。句読点の後ろは、次の本文の字まで書き込みを受けない（`之。を` は誤り）
- `AーB` は A と B をつなぐ竪点。`AーBーC` は A〜C の 1 つの竪点
- `｜` から次の読み仮名の `（…）` までが、範囲の読み仮名。範囲の中の字は、読み仮名以外の書き込みを持てる
- escape の記号の直後の書記素クラスタ 1 つは、記号でも仮名でも本文の字になる
- 空白（ASCII の空白、タブ、全角空白）は読み飛ばす

### 改行とブロック

- CRLF と CR は LF として読む
- 空白だけの行は空行。1 つ以上の空行でブロックを区切る。文字列の最初と最後の空行は無視する
- ブロックの中の改行は、前の行の最後の字の後ろの改行になる。ブロックの最後の行の後ろには改行を作らない
- 読み仮名の範囲や竪点の語の中の改行は誤り（`INVALID_LINEBREAK`）

## 設定

呼ぶ側の設定（`createParser(options)` の `options`）で、機能を切り、記号を差し替える。文書の中には書かない。差し替えられるのは記号だけで、規則（構文）は変わらない。型は [API リファレンス](skam-api-reference.md#kanbun-skamskam-text-parser) にある。

- `features`: 8 つの機能（`kaeri`、`okurigana`、`yomigana`、`kutoten`、`linebreak`、`saidoku`、`soegana`、`tateten`）の有効・無効。省いた機能は有効
- 切った機能は記号を持たないので、その記号は本文の字になる。例えば添え仮名を切ると `＋` は本文の字、送り仮名を切ると仮名は本文の字。改行を切ると、ただの改行は空白として読み、空行のブロックの区切りは残す
- `symbols`: 機能ごとの記号。指定した機能の記号だけが既定と入れ替わる
- 有効な機能の記号、escape の記号、予約の記号の中で、同じ記号か、一方が他方の前方部分である組があると、`createParser` が `NotationConfigError`（`SYMBOL_CONFLICT`）を投げる。空の記号は `EMPTY_SYMBOL`
- `maxInputLength`: 入力の長さの上限（UTF-16 単位、既定 100,000）。超えた入力は、書記素に分ける前に `INPUT_TOO_LONG` で止まる。既定値は信頼できない入力を受けるときの守りで、上げるかどうかは呼ぶ側のアプリが決める。入力の文字列の側からは変えられない。1 以上の整数でなければ `INVALID_LIMIT`

## 結果と診断

`parse` は `{ ok: true, document, diagnostics }` か `{ ok: false, diagnostics }` を返す。誤りの診断が 1 つでもあれば文書を返さない。警告だけなら文書を返す。

診断の位置は、改行を LF に直した後の文字列の行と桁（1 始まり、UTF-16 単位）。`endLine` と `endColumn` は範囲の直後を指す（範囲に含まない）。`學（まな` の誤りは 1 行 2 桁から、`endColumn` 5 まで。

記法の読み取りで出る誤り:

| code                   | 意味                                                                              |
| ---------------------- | --------------------------------------------------------------------------------- |
| `INPUT_TOO_LONG`       | 入力が `maxInputLength` を超えた                                                  |
| `UNCLOSED_SYMBOL`      | 対の記号や範囲の読み仮名が閉じないままブロックが終わった。escape の後ろに字が無い |
| `UNEXPECTED_CLOSE`     | 開いていない閉じる記号                                                            |
| `ORPHAN_ATTACHMENT`    | 付ける字の無い書き込み（ブロックの先頭、句読点の後ろ）。前か後ろに字の無い竪点    |
| `DUPLICATE_ATTACHMENT` | 1 つの字に同じ種類の書き込みが 2 つ                                               |
| `EMPTY_VALUE`          | 中身の無い読み仮名・返り点・添え仮名・再読                                        |
| `INVALID_VALUE`        | 読み仮名・再読の値に仮名でない字                                                  |
| `INVALID_KAERI`        | 返り点に書けない字                                                                |
| `RESERVED_SYMBOL`      | 予約の記号 `「」『』`                                                             |

読み取りに誤りが無ければ、組み立てた文書を `validateSKAMDocument` で検査する。その誤りと警告は、validator の code（例 `INVALID_LINEBREAK`、`SAIDOKU_READING_OVERLAP`）のまま、記法の位置を付けて返す。
